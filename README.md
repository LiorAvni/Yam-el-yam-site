# אתר תכנון מסלול ים אל ים

אתר React/Vite מוכן לפריסה ב-Vercel.

## הרצה מקומית
```bash
npm install
npm run dev
```

## בנייה לפרודקשן
```bash
npm run build
```

## פריסה ב-Vercel
1. מעלים את התיקייה ל-GitHub.
2. ב-Vercel בוחרים New Project.
3. בוחרים את הריפו.
4. Framework Preset: Vite.
5. Build Command: `npm run build`.
6. Output Directory: `dist`.

## מפה
קובץ ה-GPX נמצא ב:
`public/route.gpx`

האתר טוען אותו אוטומטית ומציג את המסלול והנקודות המסומנות.
